- RQ2. 분류 오류가 개인별 초가공식품 에너지 비율(UPF%)의 모집단 평균 추정을 얼마나 바꾸는가?

- 자료: 국민건강영양조사 2019-2022년 24시간 회상(`hn19~22_24rc`), 19-59세.
- 분석 단위: 서로 다른 식품코드(`N_FCODE`) 3,142개.

  - `대표_응답식품명`·`대표_음식명`은 사람 배정자의 참고 정보로만 쓰고 분류기 입력에서는 뺀다.

## 3. 정답셋(평가셋)

### 3.1 표본

- 상위층: 에너지 기여 상위 200개 코드 전수 (19-59세 식품 에너지의 81.1%)
- 꼬리층: 나머지 2,942개에서 식품군 비례 층화 무작위 200개 (시드 20260914)
- 합계 400개. `03_sample_gold.py`로 재현한다.
- 이 400개 코드는 규칙·프롬프트·few-shot 예시 개발에 쓰지 않는다. few-shot 예시와 보정 연습 코드는 표본 밖에서 고른다.

### 3.2 배정 프로토콜

- 배정자는 `gold_rater_A/B.csv`만 보고 배정한다. 템플릿에는 분류기 예측이 없다(맹검).
- 채울 열: `nova`(1-4), `uncertain`(0/1: 합리적인 배정자 사이에 판단이 갈릴 수 있음), `rule`(아래 D 번호), `note`
- 판단 기준은 "이 코드로 입력된 섭취가 전형적으로 어떤 형태인가"이다(에너지 기여가 큰 형태 기준, 대표 응답식품명·제품명 참고).
- NOVA 정의는 Monteiro 등(2019)을 따른다. 한국 식품에 대한 결정 규칙은 다음과 같다.
  - D1 물리적 처리(세척·절단·건조·냉동·삶기·분쇄·살균)만 거친 식품은 1군. 쌀·밀가루·건조 파스타·생고기·생선·달걀·우유·무가당 플레인 요구르트·원두커피·녹차·100% 과일주스 포함.
  - D2 1군에서 추출·정제한 요리재료(설탕·물엿·꿀·식용유·참기름·버터·소금·식초·전분)는 2군.
  - D3 1군에 소금·설탕·기름 등을 더한 전통적 가공(절임·염장·발효·통조림·단순 조림)은 3군. 김치·젓갈·장아찌·재래 장류·두부·떡·국수·조미김·자연치즈·잼·청·발효주(맥주·와인·막걸리·청주) 포함.
  - D4 산업용 원료·첨가물(향료·색소·유화제·감미료·가공전분·경화유·조미료 등)이 들어간 즉석 섭취 제품은 4군. 라면·과자·양산빵·케이크·가공육·어묵·맛살·탄산·가당음료·가공우유·액상요구르트·믹스커피·아이스크림·드레싱·마요네즈·케첩·복합조미료·인스턴트 국 포함.
  - D5 증류주(희석식 소주·위스키 등)와 증류주 기반 혼성주는 Monteiro 2019에 따라 4군.
  - D6 빵·케이크·도넛은 한국 시판품 대부분이 유화제·제빵개량제·마가린을 쓰므로 4군.
  - D7 조리 음식 코드(탕·찌개·볶음 등)는 주재료의 가공도로 배정한다. 제품명이 주로 레토르트·냉동 제품이면 4군이며 uncertain=1.
  - D8 시판 개량 장류(고추장·된장·양조간장)는 3군 uncertain=1, 쌈장·초고추장·춘장·혼합간장은 4군.
  - D9 제품 코드는 대표 제품의 원재료(첨가물 여부)로 판단한다. 확인이 어려우면 가장 가능성이 높은 군을 넣고 uncertain=1.
  - D10 빈칸을 두지 않는다.
- 배정자가 규칙 코드(`05_rules.py`)를 미리 읽으면 규칙 논리에 대한 맹검이 깨진다. 가능하면 배정이 끝날 때까지 읽지 않고, 읽었다면 논문 한계에 적는다.
- 절차: 2인 독립 배정 → Cohen's kappa(4범주, 4군 대 비4군, 부트스트랩 95% CI) 보고 → 불일치 합의 → `gold_labels.csv`. 배정자 간 kappa는 합의 전 값으로 보고한다.

## 4. 분류기 (정답셋 평가 전에 고정)

| ID | 방법 | 내용 |
|---|---|---|
| RULE | 규칙 기반 | v1 키워드 정규식 약 30개 + 제품코드 여부 + 17xxx 조리식품 + 식품군 기본값. v1 코드를 그대로 쓰고 수정하지 않는다. 수동 검토 덮어쓰기(override)는 쓰지 않는다. |
| ML-LR | 텍스트 ML(주) | 입력 문자열 문자 n-gram(1-3, `char_wb`) TF-IDF + 식품군·코드 첫 자리 원-핫 + 제품정보 기재 비율 → 다항 로지스틱 회귀(class_weight=balanced). C∈{0.3,1,3,10}을 내부 3겹 CV(macro-F1)로 고른다. |
| ML-SVM | 텍스트 ML | 같은 특징 → 선형 SVM, 같은 C 격자·내부 CV |
| ML-GBM | 텍스트 ML | 같은 특징(TF-IDF 상위 2,000개 특징) → LightGBM(n_estimators 300, learning_rate 0.05, num_leaves 15, min_child_samples 5, class_weight balanced), 조정 없음 |
| LLM-0 | LLM zero-shot | Qwen2.5-7B-Instruct(Apache-2.0), bf16, 결정적 추론. 프롬프트는 `prompts.py`(NOVA 정의 + 3.2의 D1-D9 요약). 답변 첫 토큰에서 "1"-"4"의 로짓이 가장 큰 값을 예측으로 한다. |
| LLM-FS | LLM few-shot | LLM-0 + 표본 밖 예시 12개(1군 2, 2군 2, 3군 4, 4군 4; `prompts.py`) |
| (탐색) LLM-14B | 모델 크기 | Qwen2.5-14B-Instruct(Apache-2.0)로 LLM-0·LLM-FS를 반복. 설치·다운로드가 실패하면 뺀다. |

- ML 평가는 정답셋 400개에서 층화 5겹 교차검증(시드 고정)의 out-of-fold 예측으로 한다.
- 규칙과 LLM은 학습이 없으므로 정답셋 전체에 그대로 적용한다.

## 5. 평가 지표

- **주 지표: Cohen's kappa(4범주)**, 정답셋 400개, 코드 단위 비가중
- 핵심 부 지표: **초가공 이진(4군 대 비4군) F1**(양성=4군)
- 기타: 정확도, macro-F1(4범주), 이진 kappa, 에너지가중 정확도(정답셋 내 코드 에너지 비율 가중), 층별(상위/꼬리) kappa, 혼동행렬
- 95% CI: 코드 단위 부트스트랩 2,000회(퍼센타일). 방법 간 차이는 같은 재표본의 쌍체 부트스트랩.
- uncertain=0 코드만의 kappa(민감도)

## 6. 하류 영향 (UPF%)

- 매핑 구성: 정답셋 400개 코드에는 각 방법의 예측(ML은 out-of-fold)을, 정답셋 밖 2,742개 코드에는 **모든 방법에 공통으로 RULE 라벨**을 넣는다. 따라서 방법 간 차이는 정답셋 코드의 분류 차이에서만 나온다.
- 기준 매핑: 정답셋 코드에 정답 라벨, 나머지는 RULE 라벨.
- 지표: 가중 평균 UPF%(전체, 19-39세, 40-59세)와 기준 대비 차이(%p), 개인별 UPF% 절대오차 평균.

## 7. 성공 기준 (수치, 사전 고정)

- **S1**: 가장 좋은 자동 방법의 4범주 kappa ≥ **0.70** (점추정). 95% CI 하한도 함께 보고한다.
- **S2**: 그 방법의 초가공 이진 F1 ≥ **0.85**
- **S3**: 그 방법 매핑의 가중 평균 UPF%가 기준 매핑과 **3%p 이내**(전체와 두 연령군 모두)
- S1-S3을 모두 충족하면 "식품명 기반 자동 분류가 정답 배정을 대신할 수 있다"고 쓰고, 하나라도 못 미치면 "보조 도구(우선순위 제시·1차 배정)로만 쓸 수 있다"고 쓴다.
- 비교 가설(탐색): H1 LLM-FS kappa > RULE kappa, H2 ML-LR kappa > RULE kappa (쌍체 부트스트랩 차이의 95% CI가 0을 넘는지). "가장 좋은 방법"은 여러 방법 중 사후 선택이므로 낙관 편향이 있음을 적는다.
