# 국민건강영양조사(KNHANES) 원시자료 — 직접 내려받기

이 폴더의 자료는 **저장소에 포함되어 있지 않습니다.** 질병관리청 원시자료 이용 규정상
제3자 제공·재배포가 금지되어 있으므로 각자 이용 신청 후 내려받으세요. (T1, T2 팀)

1. https://knhanes.kdca.go.kr → 원시자료 → 원시자료 다운로드 (회원가입·이용 동의·신청)
2. **SAS 형식**으로 다음 연도 파일을 받습니다.
   - T1: 기본자료 `hnYY_all` — 2016–2024
   - T2: 기본자료 `hnYY_all` + 24시간 회상 식품섭취조사 `hnYY_24rc` — 2019–2022
3. 압축을 풀어 `.sas7bdat` 파일을 아래처럼 둡니다(파일명은 소문자).

```
data/knhanes/sas/
├── hn16_all.sas7bdat
├── ...
├── hn24_all.sas7bdat
├── hn19_24rc.sas7bdat
└── ...
```

다른 위치에 두었다면 환경변수로 지정합니다: T1 `KNHANES_SAS_DIR`, T2 `T2_DATA_DIR`.
이용지침서(전환식, 변수 설명)도 같은 사이트에서 받을 수 있습니다.

> 받은 원시자료와 이를 가공한 개인 단위 파일(`*.pkl`, `results/`)은 GitHub에 올리지 마세요.
> `.gitignore`가 막아 두었지만 `git add -f`는 막지 못합니다.
