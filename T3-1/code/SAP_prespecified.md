## 1. 연구 질문
MSK-MET 전이 장기 예측 모델은 생물학적 신호가 아니라 **데이터 수집 흔적**(검사 패널 버전·검사 시기·검체 품질)을 학습하는가? 흔적을 통제하면(제거, 시기 분할 검증, 층화 평가, 단일 패널 제한) 성능과 SHAP 설명은 어떻게 달라지는가? (모든 서술은 "연관/예측" 수준)

## 2. 코호트
- 주 분석: `IS_DIST_MET_MAPPED == TRUE` 이고 `SAMPLE_TYPE == Primary`, 원발 불명·유전체 프로파일 없음 제외 (v1과 동일 정의; 예상 N=11,741, 환자당 1검체).
- 민감도: 매핑된 Primary + Metastasis 검체 (SAMPLE_TYPE 지표를 공변량으로 추가) — H1만 반복.
- 미매핑 4,229건은 "정보 없음"으로 제외 → 모든 대상자는 전이 장기가 1곳 이상 기록된 환자.

## 3. 결과 변수
- 장기 라벨 5개: DMETS_DX_LUNG, _LIVER, _BONE, _CNS_BRAIN, _INTRA_ABDOMINAL (Yes=1).
- 전이 부담(보조): `HIGH_BURDEN = 1[MET_SITE_COUNT >= 3]` (고정 임계값 3; 결과를 보기 전 정함). H2에서는 MET_SITE_COUNT 자체(개수)를 사용.
- 라벨은 전체 임상 경과 동안 병리 보고서 + ICD 청구 코드로 기록된 전이(Nguyen 2022, 민감도 중앙값 77%)이며 진단 시점 전이가 아니다.

## 5. 모델·검증 공통
- LightGBM 고정 하이퍼파라미터(v1과 동일: 400 trees, lr 0.03, leaves 31, min_child 20, subsample/colsample 0.8, λ=1), 튜닝 없음. 시드 20260914. n_jobs ≤ 16.
- 기본 검증: 층화 5-겹 CV out-of-fold(OOF) 예측.
- **주 지표: AUROC**. 보조: AUPRC, 기대/관찰 비(O/E, 평균 예측확률 ÷ 관찰 유병률).
- 불확실성: 쌍체 부트스트랩 2,000회 95% CI (OOF 예측 고정).

## 6. 분석과 사전 등록 성공 기준

### H1. 흔적 변수만으로 전이 장기를 예측할 수 있는가 (`03_artifact_signal.py`)
- 6개 결과(5장기+HIGH_BURDEN)마다 A, T, T+A, B 모델 OOF AUROC.
- **H1 기준(주)**: ΔAUROC(T+A − T) ≥ 0.02 이고 95% CI 하한 > 0 인 장기가 **5개 중 2개 이상**.
- H1 보조 기준: A 단독 AUROC ≥ 0.60 인 장기가 5개 중 2개 이상 (A가 원발암 구성을 대리할 수 있으므로 보조로만 해석).
- 층화 점검: T+A와 T의 OOF 예측으로 패널 층(341/410/468) 내부 AUROC를 구해 표본 수 가중 평균(“패널 층화 AUROC”)을 함께 보고.
- 민감도: Primary+Metastasis 코호트에서 ΔAUROC(T+A − T) 반복.

### H2. 흔적은 기록 강도(전이 장기 수)와 연관되는가 (`04_recording_intensity.py`)
- 포아송 회귀(강건 표준오차 HC0): MET_SITE_COUNT ~ 패널(기준 IMPACT468) + CANCER_TYPE 고정효과. 발생률비(RR)와 95% CI.
- 각 연속 흔적(PID_NUM 표준화 1SD, TUMOR_PURITY 10%p, SAMPLE_COVERAGE 100x, SEQ_LAG_YEARS 1년)도 CANCER_TYPE 보정 단변량 RR.
- 보조: 패널 모델에 FU(log OS_MONTHS+1, OS_STATUS)를 추가해 패널 RR이 얼마나 줄어드는지(추적 기간이 설명하는 비율).
- **H2 기준**: 원발암 보정 RR(IMPACT341 vs IMPACT468) ≥ 1.10 이고 95% CI 하한 > 1.
- 기술: 상위 5개 원발암 안에서 패널별 평균 MET_SITE_COUNT 표.

### H3. 흔적을 쓴 모델은 시기가 바뀌면 더 크게 무너지는가 (`05_era_shift.py`)
- 시간 분할(주): PID_NUM 순서 앞 70% = 학습, 뒤 30% = 시험. 학습 내부 5-겹 CV AUROC(“내부 추정”)와 시험 AUROC의 차이 = 일반화 격차.
- 모델 B vs B+A. 격차 차이 = 격차(B+A) − 격차(B). CI: 학습 OOF와 시험 예측을 각각 독립 부트스트랩.
- **H3 기준**: 격차 차이 ≥ 0.02 인 장기가 **5개 중 2개 이상** (CI 하한 > 0 은 보조로 보고).
- 보조 분할: 패널 간 교차(IMPACT468 학습 → IMPACT341+410 시험, 역방향). 이 분할에서는 학습 내 패널이 상수이므로 A에서 PANEL 제외. 보조 지표 O/E도 보고.

### H4. SHAP 설명은 흔적에 얼마나 기대고, 흔적을 통제하면 유전자 설명이 바뀌는가 (`06_shap_shift.py`)
- 전체 코호트로 B+A, B, B(IMPACT468만) 적합 → TreeSHAP 평균 |SHAP|.
- **H4 기준(주)**: B+A에서 흔적 변수 중 최고 순위가 전체 특징 중 **상위 10위 이내**인 장기가 5개 중 2개 이상.
- H4 보조(기술): 유전자 특징 상위 10개의 Jaccard 유사도 — B+A vs B, B vs B(IMPACT468만). Jaccard < 0.7 이면 "설명이 달라짐"으로 서술.

### M. 완화 전략 비교 (`07_mitigation.py`, 기술 분석)
- "흔적의 겉보기 이득" Δ(B+A − B)와 "유전체·임상의 겉보기 이득" Δ(B − T)를 다음 평가 방식으로 각각 추정:
  M0 무작위 5-겹 CV(전체) / M1 패널 층화 AUROC(M0 OOF를 층 내부에서 평가) / M2 IMPACT468 단일 패널 제한 CV / M3 시간 분할 시험 세트.
- 사전 판정 규칙: M3(배포 상황에 가장 가까움)을 기준값으로 두고, M0·M1·M2 중 Δ(B+A − B)가 M3에 **가장 가까운** 방식을 "가장 정직한 내부 평가"로 보고. M0의 Δ(B+A − B)가 M1 또는 M3에서 50% 이상 줄면 "흔적에 의한 성능 부풀림"으로 서술.

## 7. 다중 비교·해석 규칙
