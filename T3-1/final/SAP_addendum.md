## D1. 해결 방안 비교 (시간 분할로 평가)
전략(모두 학습 세트에서만 적합, 시험 세트는 예측에만 사용):

| 코드 | 전략 | 구현 |
|---|---|---|
| S0 | 흔적 포함(순진) | B+A |
| S1 | 흔적 제거 | B |
| S1b | 엄격 제거 | B − TMB_NONSYNONYMOUS (패널 크기 영향 변수) |
| S2 | 흔적 제거 + 라벨 완전 근사 학습 코호트 | B, 학습을 "OS≥24개월 또는 사망"으로 제한 |
| S2b | 〃 (36개월) | B, "OS≥36개월 또는 사망" |
| S3 | 흔적 제거 + 패널 균형 가중 | B, 학습 표본 가중치 = 1/학습 내 패널 빈도(평균 1로 정규화) |
| S4 | 시기 잔차화 | B의 임상·유전체 열을 학습 PID 5분위(시기 구간)별 평균으로 중심화(x − 구간 평균); 시험·검증 행은 가장 늦은 학습 구간 평균을 뺌. CANCER_TYPE 원-핫은 그대로 |
| S5a | 흔적 조건부 학습 + 고정값 예측 | B+A 적합, 예측 시 A를 기준값으로 고정(PANEL=468, PID_NUM=학습 최대, SAMPLE_ORDER=1, 순도·커버리지·SEQ_LAG=학습 마지막 PID 십분위 중앙값) |
| S5b | 흔적 조건부 학습 + 표준화(주변화) 예측 | B+A 적합, 학습 세트에서 무작위로 뽑은 K=30개 A 행으로 A를 바꿔 예측한 확률의 평균 |
| S6 | 추적 조건부 학습 + 표준화 예측 | B+FU(log OS, 사망) 적합, 학습 FU 행 K=30개로 주변화 예측 |
| S7 | 흔적·추적 조건부 학습 + 표준화 예측 | B+A+FU 적합, 학습 (A,FU) 행 K=30개로 주변화 예측 |

지표(각 전략 × 결과 × 컷):
- 내부 추정: 학습 세트(S2/S2b는 제한된 학습 세트) 무작위 층화 5-겹 CV AUROC(검증 폴드에도 같은 예측 변환 적용; 주변화는 폴드 학습 행에서 추출).
- 외부: 시험 AUROC, 시험 O/E(평균 예측/유병률), 보정 기울기·절편(로지스틱 재보정 y ~ logit p), 격차 = 내부 − 외부.
- 라벨 완전 근사 시험 부분집합(주 컷): AUROC, O/E.
- 주 컷에서 ΔAUROC(Sk − S1) 쌍체 부트스트랩 CI.

사전 판정 규칙(주 컷 c=0.70, 5장기):
- **R1 판별 비열등**: 시험 AUROC(Sk) − 시험 AUROC(S1) ≥ −0.005 인 장기 ≥ 4/5.
- **R2 정직성**: 5장기 평균 |격차|가 S1보다 작음.
- **R3 보정**: 5장기 평균 |ln O/E|가 S1보다 작음.
- **권고 전략**: R1을 만족하는 전략 중 R2·R3 충족 수가 가장 많은 것(동률이면 평균 |격차|가 작은 것). S1b–S7 중 어느 것도 S1보다 R2·R3를 개선하지 못하면 "흔적 제거(S1)만 권고, 추가 기법은 이득 없음"으로 서술.
- 가설(방향, 확증 표기):
  - **HD1** (롤링 컷 일반화): 새 컷 3개(0.5/0.6/0.8) 중 ≥2개에서 5장기 평균 |격차|가 S0 > S1.
  - **HD2** (흔적 조건부 표준화): ΔAUROC(S5b − S1) CI 하한 > 0 인 장기 ≥ 2/5. (충족 못 하면 "흔적을 보정 변수로 써도 외부 판별 이득 없음")
  - **HD3** (라벨 완전 근사 학습): (a) 시험 AUROC(S2) − AUROC(S1) ≥ +0.005 인 장기 ≥ 3/5; (b) 라벨 완전 근사 시험 부분집합에서 |ln O/E|가 전체 시험보다 작은 장기 ≥ 3/5 (S1 기준 — 보정 실패가 라벨 불완전성과 연관되는지).
  - **HD4** (잔차화): S4가 R1과 R2를 모두 충족.

## D2. 내부 평가 방식의 타당성
학습 세트 안에서 계산한 추정치가 실제 시험 성능을 얼마나 맞히는가.
- E0 무작위 층화 5-겹 CV; E1 E0 OOF의 패널 층화 AUROC; E2 시기 구간 그룹 CV(학습 PID 5분위를 폴드로, leave-one-era-out); E3 전향 홀드아웃(학습 세트 안에서 PID 앞 70%로 적합 → 뒤 30% 평가).
- 대상 모델: S0(B+A), S1(B) (E0·E3는 D1의 모든 전략에도 계산).
- 목표량: 시험 AUROC(S0), 시험 AUROC(S1), 시험 Δ_A = AUROC(S0) − AUROC(S1). 4개 컷 × 5장기 = 20점.
- 지표: 평균 절대 오차(MAE), 부호 있는 평균 오차(과대평가 방향), "흔적 추가 권고 일치율"(내부 Δ_A ≥ 0.01 여부가 외부 Δ_A ≥ 0.01 여부와 일치하는 비율).
- **HD5**: Δ_A의 MAE(E3) ≤ 0.5 × MAE(E0).
- **HD6**: AUROC 수준(S0·S1 합산 40점)의 MAE가 E3 < E0.
- 보조(기술): E2의 MAE, 전략별 E3 격차 vs E0 격차.

## D3. 중요도 방법 교차검증 (H4 강건성)
- 전체 주 코호트, B+A + 영(null) 특징 3개: NULL_NORMAL(표준정규), NULL_RANKINT(1..N 무작위 순열 정수 — PID_NUM처럼 고유값이 많은 변수), NULL_BINARY(Bernoulli 0.10). 시드 20260914.
- (i) TreeSHAP 평균 |SHAP| 순위(전체 적합) — 영 특징의 순위 = 연속 변수 편향 기준선.
- (ii) 교차검증 퍼뮤테이션 중요도: 5-겹, 검증 폴드 안에서 해당 특징(또는 묶음을 행 단위로 함께) 섞기 5회 반복, ΔAUROC = AUROC(원 OOF) − AUROC(섞은 OOF)의 반복 평균, 쌍체 부트스트랩 CI.
  - 개별: A의 각 변수, 영 특징 3개.
  - 묶음: A_시기(PANEL_*, PID_NUM), A_품질(SAMPLE_ORDER, TUMOR_PURITY, SAMPLE_COVERAGE, SEQ_LAG_YEARS), A_전체, T(원발암 27열), C(임상 9열), G(유전체 236열).
- (iii) 외부 퍼뮤테이션: 주 컷 학습 세트로 적합한 B+A를 시험 세트에서 같은 방식으로 섞음(묶음 A_시기, A_품질, A_전체, T, G, C).
- **HD7** (H4 강건): PID_NUM의 교차검증 퍼뮤테이션 ΔAUROC CI 하한 > 0 이고 점추정이 모든 영 특징의 CI 상한보다 큰 장기 ≥ 2/5.
- **HD8** (흔적 의존의 비이전): 외부 퍼뮤테이션 ΔAUROC(A_시기) ≤ 0.005 인 장기 ≥ 4/5.
- 기술: 묶음 중요도 순위(T vs G vs A), 영 특징 SHAP 순위.

## D4. 대상자 선택 vs 추적 기간 (탐색, 사전 선언)
- 결과: MET_SITE_COUNT, 포아송 회귀(HC0), 공통 보정 CANCER_TYPE. 노출: 패널(기준 468) — 341 대 468 RR 보고; 보조로 PID 십분위 추세(1SD).
- 모형: (a) 원발암만; (b) + 추적 유연 보정(OS_MONTHS 자연 스플라인 df=4 × 사망 상호작용); (c) 사망자만 + OS 스플라인; (d) OS≥36개월(생존·사망 무관) 부분집합 + OS 스플라인; (e) (b) + "시퀀싱 시점에 이미 전이 확인"(AGE_AT_EVIDENCE_OF_METS ≤ AGE_AT_SEQUENCING; 결측은 별도 범주) — 대상자 선택(진행 병기에서 검사)의 대리.
- 기술: PID 십분위별 사망 비율, OS 중앙값, 시퀀싱 시점 전이 확인 비율.
- 해석 규칙(사전 고정): (c)와 (d)에서 RR(341 대 468) ≥ 1.10 이고 CI 하한 > 1이면 "추적 기간 차이만으로 설명되지 않음(대상자 선택 등 시기 차이도 연관)"; 둘 다 < 1.05면 "추적 기간 차이가 주로 연관"; 그 외 "구분 불가". (b)→(e) 로그 RR 감소 비율은 선택 대리변수가 추가로 설명하는 몫으로 기술. 모두 연관 수준, 인과 해석 금지.
