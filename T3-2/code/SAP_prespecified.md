## 1. 연구 질문
- RQ1. 원격전이가 있는 비소세포폐암(NSCLC) 환자에서 전이 장기들은 어떤 동시발생 구조를 이루는가?
- RQ2. 그 구조는 전이 부담(전이 장기 수)을 보정한 뒤에도 남는가? (주 질문)
- RQ3. 부담 보정 동시발생 구조가 EGFR 변이군과 KRAS 변이군 사이에서 다른가?
- 모든 결과는 "연관"으로만 해석한다. 전이 순서·인과는 주장하지 않는다(라벨에 시점 정보 없음).

## 2. 데이터와 코호트
- MSK-MET (cBioPortal msk_met_2021), `data_clinical_sample.txt`, `data_clinical_patient.txt`, `data_mutations.txt`.
- 네트워크 코호트(N_net): `CANCER_TYPE == "Non-Small Cell Lung Cancer"` & `IS_DIST_MET_MAPPED == True` & `CANCER_TYPE_DETAILED != "Lung Neuroendocrine Tumor"`. 확인 결과 환자당 1검체(3,859명).
  - 라벨은 전체 임상 경과 동안의 환자 단위 라벨(Nguyen et al. 2022)이므로 동시발생 분석은 검체 유형과 무관하게 전체를 쓴다.
  - 단, 전이 검체는 채취 부위 라벨이 반드시 Yes가 되므로 원발 검체만 쓴 네트워크를 민감도 분석(S1)으로 둔다.
- 유전형 코호트(N_geno, 주 분석): 네트워크 코호트 중 `SAMPLE_TYPE == "Primary"` (2,189명). 전체 검체는 민감도(S4).
- LCNEC(대세포신경내분비암)는 NSCLC로 남기고 조직형 층으로 둔다.

## 3. 부위(노드) 선택 규칙
- `DMETS_DX_UNSPECIFIED`(부위 불명)는 노드에서 제외한다(부위 정보가 없음). 단 전이 부담 계산에는 포함한다(아래).
- 네트워크 코호트에서 유병률 **≥ 3%** 인 부위만 노드로 쓴다. 유병률 표로 확인한 결과 12개:
  폐(LUNG), 뼈, 흉막, 뇌, 간, 원격 림프절(DIST_LN), 부신, 말초신경계(PNS), 종격동, 복강 내, 담도, 신장.
  (피부 2.6% 이하 9개 부위 제외)
- 병합하지 않는다(흉막·종격동은 해부학적으로 다르고, 병합 규칙이 사후 선택이 될 수 있음).
- 폐 원발에서 `LUNG` 라벨은 **폐 내 전이(intrapulmonary metastasis)** 를 뜻한다. 노드로 유지하되 흉강 내 부위(폐·흉막·종격동)와 흉강 외 부위를 구분해 해석한다.

## 4. 변수 정의
- 부위 i 지시변수 X_i = (DMETS_DX_i == "Yes").
- 전이 부담 B = `MET_SITE_COUNT` (21개 라벨 Yes 개수, 부위 불명 포함; 21개 합과 일치 확인함).
- 쌍 (i, j)의 "나머지 부담" R_ij = B − X_i − X_j, 층은 0,1,2,3,4,5,≥6 (7층).
- 유전형(비침묵 변이 = `5'Flank` 제외 모든 변이 유형, v1과 동일):
  - EGFR군: EGFR 변이 있고 KRAS 변이 없음. KRAS군: KRAS 변이 있고 EGFR 변이 없음. 둘 다 있는 환자는 두 군 모두에서 제외.
  - STK11/KEAP1군(보조): STK11 또는 KEAP1 변이. 비교군: 둘 다 없음. EGFR 변이 환자는 이 비교에서 제외(EGFR과 거의 상호배타적이어서 교란 방지).
  - 민감도(S5) 대표 변이 정의: EGFR = L858R, L861Q, G719X, S768I, exon 19(코돈 729–761) in-frame 결실/삽입; KRAS = 코돈 12·13·61.
- 공변량: 시퀀싱 시 연령, 성별, 조직형(선암/편평상피암/LCNEC), 유전자 패널(341/410/468), 검체 유형(전체 검체 분석 시).

## 5. 분석 방법
### 5.1 주변(marginal) 동시발생 — RQ1
- 66개 쌍마다 2×2 표: 오즈비(OR; 칸에 0이 있으면 모든 칸 +0.5), 리프트 = P(i,j)/(P(i)P(j)), Jaccard.
- 검정: Fisher 정확검정(양측), 66쌍 BH-FDR. 유의 기준 FDR < 0.05.

### 5.2 부담 보정 동시발생 — RQ2 (주 분석)
- **주 지표**: R_ij 7층으로 층화한 Mantel–Haenszel 공통 OR (log 척도를 간선 가중치로 사용), Cochran–Mantel–Haenszel 검정(연속성 보정 없음), 66쌍 BH-FDR < 0.05.
  - 이는 "나머지 부위 수가 같은 환자끼리 비교했을 때 두 부위가 함께 나타나는 경향"이다.
  - MH 분자 또는 분모가 0이면 모든 층의 모든 칸에 +0.5를 더한다.
- **보조 1 (영모형)**: 환자별 선택 12개 부위 수(행 합)와 부위별 유병률(열 합)을 모두 보존하는 curveball 무작위화(Strona et al. 2014). 열 쌍 교환 방식, 번인 2,000회 교환 후 50회 교환마다 1개 표본, **B = 1,000** 개 영행렬, seed 2026. 쌍별 관찰 동시발생 수 vs 영분포: z = (obs − mean)/sd, 양측 경험적 p = (1 + #{|null − mean| ≥ |obs − mean|})/(B + 1), BH-FDR.
- **보조 2 (조건부 네트워크)**: eLasso 방식 Ising 모형(van Borkulo et al. 2014). 부위마다 나머지 11개 부위를 L1 로지스틱 회귀, C 격자 50개(로그 간격 1e-3~10), EBIC(γ = 0.25)로 선택, **AND 규칙**, 간선 가중치 = 두 계수 평균. 공변량 없음.
- **보조 3 (공변량 보정 로지스틱, S2)**: X_j ~ X_i + C(R_ij) + 연령 + 성별 + 조직형 + 패널 + 검체 유형 (연령 결측 제외), X_i 계수의 OR, BH-FDR.
- 주변 vs 보정 비교: 66쌍의 log OR 차이(보정 − 주변) 중앙값과 주변 유의 → 보정 후 비유의로 바뀐 쌍 수를 보고한다.

### 5.3 연관 규칙 (보조, 해석용)
- 선행 1–2개 부위 → 결과 1개 부위. 최소 지지도 0.05, 최소 신뢰도 0.5. 리프트 순 상위 5개와, 결과가 뇌인 규칙 중 리프트 상위 3개를 보고한다. 규칙은 부담 보정이 없으므로 5.2와 함께 제시한다.

### 5.4 유전형별 네트워크 비교 — RQ3
- 유전형 코호트(원발 검체)에서 EGFR군 vs KRAS군.
- 비교 대상 쌍: 두 부위의 유병률이 **두 군 모두에서 ≥ 5%** 인 쌍만(적격 쌍).
- 군별 간선 가중치 w = log MH OR (5.2와 같은 층화). Δ = w_EGFR − w_KRAS.
- 순열 검정: 조직형 × 패널 층 안에서 군 라벨을 섞음, **B = 2,000**, seed 2026. 양측 p = (1 + #{|Δ*| ≥ |Δ|})/(B + 1). 적격 쌍 BH-FDR, 유의 기준 **FDR < 0.1**.
- 전역 검정: S = Σ|Δ| (적격 쌍 합), 같은 순열 분포로 p. 군별 전역 강도 Σ|w| 도 보고.
- 전이 부담 차이: B ~ 군 + 연령 + 성별 + 조직형 + 패널, Poisson GLM(log link, HC0 robust SE), 비율비(RR) 보고.
- 보조 비교: STK11/KEAP1군 vs 둘 다 없음(EGFR 제외), 같은 방법, 탐색적(FDR < 0.1).

### 5.5 모듈(선택, 지면 허용 시)
- 5.2 주 분석에서 FDR < 0.05이고 log OR > 0 인 간선(가중치 = log OR)으로 Louvain 모듈성 최적화(해상도 1), 노드 순서 무작위 100회 중 모듈성 최대 분할, seed 2026.

## 7. 주 지표와 성공 기준 (결과 보기 전 확정)
- **C1 (주, RQ2)**: 부담 보정 MH 분석에서 FDR < 0.05인 부위 쌍이 **3개 이상**.
- **C2 (강건성)**: C1 쌍 중 **2/3 이상**이 curveball 영모형에서도 FDR < 0.05, 같은 방향.
- **C3 (RQ3)**: EGFR vs KRAS 적격 쌍 중 Δ 간선이 FDR < 0.1인 쌍이 **1개 이상**.
- 보고용 가설(성공 기준 아님): 주변 log OR보다 부담 보정 log OR이 대체로 작다(66쌍 차이 중앙값 < 0).
- C3을 충족하지 못하면 "이 표본 크기에서 유전형 간 차이를 검출하지 못함"으로 보고하고, 전역 검정과 효과 크기(Δ) 분포를 함께 제시한다. 실패도 결과로 보고한다.
