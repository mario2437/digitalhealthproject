## 실행
```bash
bash code/run_all.sh                 # ../results, ../figures 에 저장
bash code/run_all.sh /path/to/out    # /path/to/out/results, figures 에 저장 (또는 T1_OUT 환경변수)
```
- Python: `dh` conda 환경의 `python` (환경변수 `PY`로 변경 가능). 자료 경로 기본값은 `data/knhanes/sas/`, `KNHANES_SAS_DIR`로 변경 가능.
- 시드 2026, 부트스트랩 1,000회, ICI 영점 500회, 병렬 최대 16. 전체 약 6-10분(서버 부하에 따라 다름). 같은 입력이면 CSV가 바이트 단위로 같게 재현됩니다.
- 논문 변환: `python ../common/md2docx.py draft/초안_심사용.md draft/초안_심사용.docx` (T1 폴더에서 실행)

## 진행 순서(중요)
1. `code/SAP_prespecified.md`를 팀이 읽고 동의하거나 수정한 뒤 **결과를 보기 전에** 확정합니다. 수정했다면 맨 위에 새 `date` 시각을 적으세요.
2. `01`, `02`는 결과변수를 쓰지 않으므로 먼저 실행해도 됩니다. `03` 이후는 SAP 확정 뒤 실행합니다.
3. 결과를 본 뒤 기준 수치를 바꾸지 마세요. 추가 분석은 "사후 분석"으로 표시하고 기록합니다.
4. `results/criteria.csv`의 판정을 그대로 논문에 적습니다(미충족도 보고).

## 팀이 결정할 사항
- 기준 구간: 2016-2018(제7기, 현재) vs 2016-2019 또는 제8기(2019-2021) 기준. 기준에 따라 "변경" 연도가 달라집니다.
- 미진단 당뇨병: 제외(현재). 판정 척도는 조화 HbA1c로 고정해 시나리오 간 대상자를 같게 함(원자료 척도 코호트는 민감도).
- 좌식·수면시간 포함 여부: 수면 문항 형식이 연도마다 바뀌어(시각 문항 ↔ 하루 평균 시간 문항) 공변량 이동 진단에 영향.
- 분해 순서(측정→공변량→절편)와 몫을 계산하는 최소 초과오차(0.01).
- 논문 분량: 표 2와 대사증후군 문단 중 무엇을 줄일지.
- 표본설계 가중치 반영 여부(현재 비가중; 한계로 기술).

## 주의
- 절편 재보정(S3)은 해당 연도 결과를 쓰는 "오라클" 보정이라 실제 배포에서는 바로 쓸 수 없습니다(상한값 해석).
- 공식 전환식은 이용지침서 기준입니다: HbA1c 2022년 이후 y=1.034x-0.0448, 성인 혈압 2021년 이후 Greenlight 척도 전환식, 중성지방 2005-2021년 y=0.99x+11.94(새 방법 척도로). 허리둘레 줄자(2019)와 HDL(2022)은 전환식이 없습니다.
- LightGBM 같은 유연한 도메인 분류기는 값의 기록 단위(정수 vs 0.5 단위, 문항 형식) 차이를 쉽게 잡아 AUROC가 크게 나올 수 있습니다. 임상적으로 의미 있는 분포 차이와 구분해 해석하세요.
- 전환식 적용 후 값은 공식 통계와 다를 수 있습니다(질병관리청 공식 통계는 원자료 사용).
- 연관만 해석합니다. 측정 변경과 실제 건강 수준 변화는 완전히 분리되지 않습니다.
